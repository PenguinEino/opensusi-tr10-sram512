# SRAM512仕様

## 基本仕様

| 項目 | 値 |
|---|---|
| 容量・構成 | 512 bit、16行×32列、6T SRAM |
| アクセス | 1 bit単位、アドレス `32 × RA + CA`（0〜511） |
| アドレス長 | RA: 4 bit、CA: 5 bit |
| 電源・論理レベル | VDD=5 V、VSS=0 V。HIGH=VDD、LOW=VSS |
| 外形 | 横1776.7×縦600.0 µm |
| 提出GDSトップ | `sram512` |
| PDK | TR-1um dev、`6afbd918951f2ea0dcd11c5a46986b4c20f9e6f9` |

## 端子

全端子M2（GDS 20/0）。座標はµm、原点はコア左下。

| 端子 | 方向 | 機能 | X | Y |
|---|---|---|---:|---:|
| VDD | 電源 | 5 V | 1747.7 | 597.3 |
| VSS | 電源 | 0 V | 1769.7 | 597.3 |
| CLK | 入力 | 立上りで1段階進む | 1101.7 | 1.7 |
| RESET | 入力 | HIGHで非同期リセット | 1244.7 | 1.7 |
| SDI | 入力 | アドレス・書込みデータ | 1393.2 | 1.7 |
| WE | 入力 | E0で取り込み。1=書込み、0=読出し | 1530.7 | 1.7 |
| SDO | 出力 | 読出し結果1 bit、BUF_X4付き | 1684.7 | 1.7 |

## シーケンス

1操作＝受信10クロック＋アクセス8クロック。SDIはMSBから送る。

```text
RA3 RA2 RA1 RA0 CA4 CA3 CA2 CA1 CA0 DIN
```

各行はCLK立上り後の動作。指定のない信号は前段階を保持する。

| CLK番号 | 段階 | 動作 |
|---|---|---|
| 1〜10 | 受信 | SDIを取り込み。WL・書込み駆動はOFF |
| 11 | E0 | WEを記憶、プリチャージON。読出し時はSAリセット |
| 12 | E1 | プリチャージOFF |
| 13 | E2 | 書込み時：DINに応じて片側プルダウンON |
| 14 | E3 | 選択WLをON |
| 15 | E4 | 読出し時：SAEをHIGHにして判定 |
| 16 | E5 | WLをOFF |
| 17 | E6 | 書込み時：プルダウンOFF。読出し時：SDOへ結果を保持 |
| 18 | E7 | 操作終了。次の立上りから次フレームの受信 |

- 電源投入時はCLK=LOW、RESET=HIGH。電源安定後にRESETを解除し、受信を開始する。
- SDIは受信クロック、WEはE0の立上り前後で安定させる。読出し時もDINのクロックは必要（値は任意）。
- SDOは読出しE6の後に更新。外部ではE7後に読む。受信・書込み中は前回値を保持する。
- RESETは制御・受信位置・SDOを0にする。SRAM内容は初期化しない。電源投入直後の内容は未定義。
- 書込み途中にRESETした場合、そのアドレスへ再書込みする。

## 確認条件・接続

| 試験 | 条件 |
|---|---|
| 同梱TB | 5 V、27°C、CLK周期1 µs、四隅の書込み・読出し16操作 |
| 詳細RC試験 | CLK周期5 µs（90 µs/操作）、duty 50%、入力遷移5 ns、SDO負荷10 pF |
| 詳細RCの入力更新 | SDI更新開始はCLK立上り開始の1.25 µs前 |
| 詳細RCの電源・温度 | 5 V / 27°C、4.5 V / 85°C / 信号RC×3で合格 |

配線RCは仮定係数によるモデル。校正済みPEX・限界速度・統計ミスマッチは未評価。
最大MOS端子間電圧5.7475 V、検証上限5.75 V（余裕約2.5 mV）。

パッド配線・パッドESDは共通フレーム側。コア入力4本にはDP/DNクランプ各1組を実装済み。
フレーム側保護との重複があり、追加クランプの要否・統合後のESD耐性は未確認。
