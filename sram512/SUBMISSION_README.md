## アピールポイント

- **セル面積・ビット密度**：22×29.6 µm、651.2 µm²/bit。セル単体で約1,536 bit/mm²。
- **提出枠の使用率98.7%**：周辺回路込み1.0660 mm²を横1800×縦600 µm（1.0800 mm²）の枠に収容。周辺回路込みの密度は約480 bit/mm²。
- **書込み回路とセンスアンプを32列で共有**：列選択回路で接続先を切り替え、共通の書込み回路と7Tセンスアンプで1 bitずつ読み書き。
- **シリアル方式で端子数を削減**：アドレスを順番に入力し、電源込み7端子で全512セルにアクセス可能。

Drawing DRC 0・厳密LVS一致（13回路）・製造マスクDRC 0。
