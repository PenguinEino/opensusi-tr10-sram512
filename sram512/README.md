# 16行 × 32列・512 bit SRAM

2026-09-12着手。実装・検証中。製造用リリースではない。

## 固定した仕様

- 6Tセルは `klayout/sram_pcell/build.py` の six_single 版。22.0 × 29.6 µmピッチ。
- 16行、32列、1 bit単位の読み書き。行4 bit、列5 bit。
- 7端子：VDD / VSS / CLK / RESET / SDI / WE / SDO。
- 外部CLKの立上りで進行。RESETはHIGHで非同期。
- RA[3:0]、CA[4:0]、DINの順にMSBから10 bit受信。その後E0〜E7の8クロック。
- 受信FFとアクセス中の保持FFを共用。WEはE0、SDOは読み出しE6で記憶。
- 既存の静的CMOSプリデコード、WL許可、nMOS列MUX、片側プルダウン、7T SAを継承。
- 縦600 × 横1800 µm以内は必須条件。物理配置も16行×32列を維持する（2026-09-12ユーザー確認）。パッドへの配線は主催者側で行う前提。提出コアは7端子を外周へ出し、位置と電源条件を記載する。パッドセル自体はこのコアへ追加しない。

## 基準確認の結果

devのPCellから新たに生成した16×32アレイは768.2 × 473.6 µm。
公式Drawing DRCは0件、公式LVSは端子の厳密な照合を含めて一致した。
候補スタセル15種類もすべてDRC 0。

PDK配布GDSには、BUF_X4のGND、NAND3とOR3のVDDラベルが欠けていた。
またNAND3のA/C、OR3のB/C、OR4のA/Bラベルは回路図のトランジスタ直列順と異なっていた。
**設計側のコピーの端子ラベルだけを修正**し、15種類すべての厳密なLVS一致を確認した。
論理を通すために端子照合を無効にしたのではなく、個々のトランジスタ接続に照合している。
この基準段階では、設計コピーの端子ラベルだけを変更した。
後述のaccess.pyによる配線追加は、別途DRC/LVSで検証する。PDK本体と検証デッキは無改変。
このコピーの生成は `prepare.py` で再現できる。

```bash
python3 sram512/prepare.py
```

結果：`reports/array_baseline.json`、`reports/library_baseline.json`、
`reports/library_interfaces.json`、`reports/library_interface_corrections.json`。

専用回路図の入口は [`sram512.sch`](../sram512.sch)、TBは [`sram512_tb.sch`](../sram512_tb.sch)。
[操作仕様](SPEC.md)。論理回路の照合は334,063回、全512アドレスを含む9,270操作で合格。
全512セルと実周辺MOSを接続した基準SPICEは、5 V・27°C・1 µs周期にて
16操作、3,669項目で合格。追加8条件（4.5/5.5 V、−20/85°C、配線負荷3倍、
1 pF/線、NMOS/PMOSのVth感度±0.1 V）も各3,669項目で合格。
これらはパラメータ感度試験であり、PDKの統計的製造コーナーではない。製造用レイアウトと抽出後の確認はまだ残っている。

`layout_analog.py` で作る1列／32列のPC・nMOS MUXブロックも、
無改変devルールでDRC 0、厳密なLVS一致を確認した。
32列版は768.2 × 77.6 µm（タップ・共有電源配線を含む）。
列ピッチ22 µm、16列ごとの間隔21.2 µmをアレイと合わせている。
これはまだデコーダ・SA・コントローラを含む完成マクロではない。

## 周辺回路の物理実装（作業中）

`layout_sense.py` の共通PC・書込PD・7T SAはDRC 0・厳密なLVS一致。
`access.py` はスタセルの設計側コピーに配線の引き出しを追加する。
AND3・AND4は元のスタセルに、フィールド上の配線延長とGC接点を追加した。
AND4は元の33 µm幅を保ち、C/Dには電源配線の上側にも取り出しを設けた。
DFFRには既存RESETゲートのフィールド上の配線延長とGC接点を追加した。
これらもすべて元のXschemトランジスタ回路へ照合し、15種のDRC 0・LVS一致を確認。
PDK本体と検証デッキは変更していない。

統合版は16列ごとのタップ間隔を22 µmへ広げる（セルピッチは22 × 29.6 µmのまま）。
そのアレイは769 × 473.6 µm。列回路の共通VSSは下側のM1に配線して、
列プリデコードのM2配線領域を確保する。これらの独立マクロもDRC/LVS合格。
全体の配置配線・抽出後検証は引き続き実装中。

## 16列ずつの物理分割

提出用は、セル配列を回転せず、縦16行・横32列とする。
`layout_bank_core.py` の16×16ブロックを横に2個並べる。各ブロックには
16列分のPC/MUXを含め、列選択ANDは右側の制御回路とまとめて配置する。
このブロック単体は395 × 552.8 µmで、無改変devのDRC 0・厳密LVS一致を確認した
（`reports/layout_bank_core16.json`）。セルとPC/MUXの回路・寸法は維持する。
各論理行にはAND3_X1を2個置き、左側16セルと右側16セルを別々に駆動する。
両側は同じプリデコードとWL_ENに従う。シリアル操作仕様は変わらない。
この回路図で全アドレス論理試験と基準トランジスタ試験3,669項目は合格。
電源・温度・負荷・Vthの8感度条件も、変更後の回路で各3,669項目に合格。
全体配置配線および抽出後検証は未完であり、製造可能とは判定していない。

これ以前の `layout_bank.py` と720 µm比較配置は、回転した16×16ブロックに
列選択ANDも含めていた。これらの合格結果は比較用であり、新しい配置の合格を
意味しない。入力クランプは隣接スタセルのウェル下端23.2 µmに対応させ、
下側ダイオードを下げた別配置を用意した。ダイオード寸法は3.6 × 3.6 µmのままで、
こちらも単体DRC 0・LVS一致（`reports/input_clamp_compact_row.json`）。

専用TBをGUIで開く場合は `python3 sram512/open.py` を使う。
本体は `python3 sram512/open.py --circuit`。
これはユーザーの既存設定を変更せず、検証と同じ隔離dev PDKを選択する。

感度試験の4.5/5.5 Vや−20°Cを、そのまま製品の保証範囲とはしない。
公開モデル資料の電圧・温度適用範囲を外れる条件は参考ストレス条件として扱う。
検証の基準は5 V・27°Cであり、統計ばらつきモデルによる歩留まり保証ではない。

## 配線済みの比較配置

`python3 sram512/layout.py --height 720 --iterations 1800` で生成する比較配置は、
158ネットの配線が完了し、無改変devのDrawing DRC 0・厳密LVS一致を確認した。
結果は `reports/layout_h720.json`。外形は約720×1800 µmであり、目標の
600×1800 µmに収まったという意味ではない。抽出後の動作・配線RC・電流評価、
製造レイヤー変換、提出先の端子・ESD条件の確認も引き続き必要。

[`sram512_macro.sch`](../sram512_macro.sch) は本体を含む7端子の階層で、
GDS最上位は `sram512_macro`。内側の実配線に回路図と対応するネット名を付け、
SRAMの大量の同形セルをLVSで照合しやすくしている。外部端子は7本のまま。
`physical_top.py` は実回路図から参照ネットリストを作る。端子の無視や
ブラックボックス化は行わない。

配線スクリプトは下位セルの内部ネットも障害物に含める。細い同一ネット内の
接続部を修正する場合は、実際にM1形状を追加し、その後に公式DRC/LVSを再実行する。
`--poly-rows`、`--row-clamps`、600/660 µm配置、`layout_bank.py --compact` は未合格の検討用。
それらを提出用レイアウトとして使わない。

## 抽出後の確認と残っている電源配線の問題

136操作のトランジスタ試験は全16行・全32列を通り、45,429項目で合格した。
全512アドレスの網羅は論理試験で行い、トランジスタ試験では行・列と両データを
代表アドレスで確認している。結果は `reports/analog_decode_coverage.json`。
長いシーケンスでも5 nsの入力エッジが丸められないよう、PWLの時刻は秒単位で
12桁の指数表記にした。隣接イベントの時刻が厳密に増加することも確認する。

`postlayout.py` は公式LVSで一致した物理ネットリストから、接続・W/L・接合面積と
周長・並列フィンガ数を取り出す。LVSの対応表は観測ネット名の対応付けにのみ使う。
5081個の物理MOSを含む抽出回路は3,669項目で合格した。
入力ダイオード追加後の版も同じ項目に合格している。

`wire_rc.py` は実配線の面積・周長に明記したR/C係数を掛ける感度試験用。
BL・WL・共通線を4分割し、その他のゲートにも距離に応じたRC枝を付ける。
初回の比較配置は、配線遠端と21個のFFのクロック枝を含む26,197項目で合格。
係数は公開PDKで校正されたPEX値ではなく、電源配線の抵抗もまだ含まない。
R/C倍率・配置更新後の再検証が必要であり、この結果だけを製造保証に使わない。

CLK/RESET/SDI/WEには、dev PCellの3.6×3.6 µmのDP/DNを一組ずつ接続した。
これは製造マスク検査で指摘された浮遊ゲートへの対策で、パッド用ESD保護とは異なる。
`layout_inputs.py` の実回路・レイアウトは独立のDRC 0・LVS一致を確認。
全体もDrawing DRC 0・LVS一致で、`manufacturing.py` による公式MDP変換後の
IP62マスクDRCも0件。waiver領域やチェック除外は使っていない。
ngspiceは公開ダイオードモデルのIMAX/IMELTを扱わないため、その2項目の診断を
結果JSONに明記する。通常のI/V・C/Vモデルは原本をそのまま読み込み、
損傷限界・ESD耐量をシミュレーションで保証するものとはしない。

## 電源経路・運用条件の追加検証

`power_grid.py` は実際のM1/M2/V1だけの接続グラフを作り、基板を配線代わりに
していないことを確認する。元の比較配置では、約15 mAの全体ピークが単一ビアを
通る経路があった。M1の追加、並列ビア、別経路の追加を行った
`build/sram512/layout/power_bypass_h720/` はDrawing DRC 0・厳密LVS一致。
公式MDP変換後のマスクDRCも0件である。GDSのSHA-256は
`edc28e137131a870bd7d0a99b587b472b969a861329af68d25aaf9493da63b20`。
主要なGND経路のビア数は4／3／3個となった。これは実形状の個数であり、
各ビアへの電流の均等分担を保証する数値ではない。

`power_rc.py` は、この実配線の接続と形状から電源抵抗の感度モデルを作る。
金属0.1 Ω/□、ビア1 Ω/個を仮定した試験では、16操作のセル・SDOの値は一致したが、
内部信号の90%／10%電圧窓で101件の不適合が出た。VDDの最小は約4.04 V、
VSSの最大は約1.04 Vだった。**この電源抵抗条件は不合格であり、改良が必要。**
係数は公開PDKで校正された値ではない。モデルは接続金属ごとの半周長と最小線幅を
使う保守的な分岐モデルで、基板抵抗や個別ビアの電流分担を解いたPEXではない。
結果は `reports/power_rc_sheet_01.json` に不合格のまま保存する。

入力ダイオード付き抽出回路の信号RC 3倍・4.5 V・85°C試験は、遠端を含む
26,197項目で合格した（`reports/signal_rc3_low_hot.json`）。
`operational_tests.py` では、20 µsの電源立上り、85°Cで1 msのクロック停止保持、
受信／プリチャージ／書込／読出中の10通りの非同期RESETを確認した。
抽出回路で28操作・6,933項目が合格した（`reports/operational_hot.json`）。
RESET中断時の書込対象ビットは値を保証せず、再初期化して再読出しを確認する。
それ以外の既知のセルは中断中にも保持を検査する。

`layout_inputs.py --compact` の別配置では、同じDP/DNの接合面積・周長を保ったまま
電源レール上に基板／ウェル接点を置き、配置幅を33から16.5 µmへ縮小した。
単体DRC 0・LVS一致。全体への適用と、太い電源幹線を先に確保する配置は検討中。
この単体結果で完成マクロの合格を代用しない。

`electrical_limits.py` は抽出された5,005組のMOSについて、DS / GS / SB / DB /
GD / GBの全端子間電圧を検査する。通常条件の30,030項目と基本動作3,669項目は
合格した（`reports/voltage_envelope_nominal.json`）。最大値は5.590 Vで、
devのOS00リファレンスマニュアルrev1.1・表I-2-3の推奨動作上限5.75 V以内。
この結果は当該GDS・通常条件に対する検査であり、電源抵抗を含む最終条件は別途確認する。

`power_mesh.py` は実金属の中心経路・局所線幅・分岐・ループ・各ビアを使う、
別の電源抵抗感度モデル。直線配線の解析解との比較と、並列経路を保った抵抗網の
縮約を検査した。0.25 µmの標本化、0.1 Ω/□、1 Ω/ビアでは、比較配置の基本動作
3,669項目が合格した（`reports/power_mesh_01_klu.json`）。過渡的な電源変動は残り、
最小VDDは4.309 V、最大VSSは1.056 V。この合格は既存の動作・電圧窓を満たすという
意味で、電源変動が十分小さいという判定ではない。600 µm配置では幹線を先に確保する。
こちらも校正済みPEXではなく、任意の接合部形状に対する数学的な上限保証はない。
先の全ポリゴン周長モデルによる不合格結果は削除・置換しない。

大きな観測リストはngspiceの`save`を100項目ずつに分ける。`save: too many args`を
見逃さない検査を追加し、端子電圧試験もこの方式で再実行して合格を確認した。
波形の読込みは読取り専用のメモリマップとし、データ全体の重複コピーを避ける。
KLUはオプションで選択できるが、素子モデルや判定しきい値は変えない。

電源条件の改善、600×1800 µmへの収容、主催側パッド・ESD・ピン位置との照合が
残っている。現在のGDSは検証途中の比較配置であり、製造用リリースではない。
